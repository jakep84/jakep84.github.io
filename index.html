C++ Scripting Language

Gizmo

Gizmo is a lightweight scripting language and interpreter written in C++. It began as a simple command interpreter and evolved into a small scripting runtime with variables, arithmetic, conditionals, loops, script execution, persistence, chained commands, and runtime validation.

Key Features

  • Variables, arithmetic, and numeric comparisons
  • if/else, repeat loops, and while loops
  • Nested and chained command execution
  • Executable .giz script files
  • Save and load persistence
  • Error handling and infinite-loop protection

What I Learned

Gizmo taught me a lot about interpreter design, command parsing, input validation, refactoring, class responsibility, edge-case testing, and maintaining software as the feature set grows. I also used GitHub Issues, branches, Pull Requests, and a Project board throughout development.

Automation • Web • Data

Daily Knowledge Garden

Daily Knowledge Garden is an automated information pipeline that gathers and organizes useful daily information into a continuously updated GitHub Pages website.

Key Features

  • Automated daily content generation
  • GitHub Actions workflow automation
  • Global and local news aggregation
  • NASA astronomy content
  • Wikipedia knowledge feeds
  • Automatically published GitHub Pages site

What I Learned

This project helped me improve at building reliable automation pipelines, debugging external data sources, organizing generated content, and using GitHub Actions as production infrastructure rather than only as a source-control tool.
